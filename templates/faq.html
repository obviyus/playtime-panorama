常见问题

答案与当前本地代码保持一致。点击问题即可展开。

1. 是否必须填写 Steam API Key？
不一定。如果站点已将 STEAM_API_KEY 或 STEAM_API_KEYS 配置为 Cloudflare Secret，网页可以留空；站点没有配置 Key 时，查询需要你在首页提供自己的 Key。
2. 我的 API Key 会上传到哪里？
Key 只保存在当前浏览器的 localStorage，并在查询时放入 X-Steam-API-Key 请求头发送到本站 Cloudflare Worker；Worker 再用它请求 Steam Web API。代码不会把 Key 写入 URL、响应正文、日志或 D1。
3. 网站会保存我的 Steam 密码吗？
不会。网页没有 Steam 密码输入框，也不执行 Steam 登录，只读取 Web API 可见的公开游戏数据。
4. 为什么我的游戏列表为空？
最常见原因是“游戏详情”未公开，或勾选了隐藏总游戏时间。也可能是账号没有超过 10 分钟的已游玩记录。请按教程修改隐私设置后重试。
5. 为什么部分游戏没有显示？
原项目会过滤累计游玩时间不超过 10 分钟的游戏；Steam API 也可能不返回某些授权类型。封面资源失败时仍会保留替代卡片。
6. 为什么家庭共享游戏没有显示？
Steam 的 GetOwnedGames 通常只返回账号拥有且允许公开的数据，家庭共享库不保证出现在响应中，本工具无法补齐 Steam 未返回的记录。
7. 为什么同一游戏只出现一次？
合并逻辑以 AppID 去重。同一账号或不同账号中的相同游戏会合并为一张卡片。
8. 多账号的游玩时间如何合并？
服务端分别读取账号，将相同 AppID 的累计分钟数相加，再按合并后的总分钟数从高到低排序。单个账号失败不会清空其他成功结果。
9. 为什么 Dota 2 等个别游戏数据可能异常？
Steam 对免费游戏、授权状态和客户端安装状态的返回存在特殊情况。工具只展示 API 实际返回的数据，无法推断缺失时长。
10. 图片为什么有时下载失败？
常见原因包括封面仍在加载、Steam 静态资源跨域请求失败、内存不足或浏览器 Canvas 限制。系统会等待图片、绘制替代卡片并自动降低超大画布比例；仍失败时请刷新或减少合并账号。
11. 手机可以使用吗？
可以。导航、表单和拼图支持窄屏，点击游戏卡片可显示名称和时长。大型图库在内存较小的手机上导出会更慢。
12. 生成结果会被网站永久保存吗？
页面本身不会保存拼图文件。成功查询的账号游戏数据会在 Cloudflare D1 中缓存 24 小时；排行榜统计来自这些缓存记录。用户名到 SteamID64 的解析缓存不会自动过期。
13. 排行榜会保存哪些数据？
D1 保存 SteamID64、游戏列表与游玩分钟数、抓取时间，以及由它们计算出的游戏数、总时长、平均时长和最常玩的游戏。不会保存 API Key 或 Steam 密码。
14. 如何清理排行榜测试数据？
当前网页没有删除按钮。站点管理员可以通过 Wrangler 对本地或远程 D1 执行明确的删除 SQL；操作前应先备份并确认目标环境。浏览器用户不能删除其他人的缓存记录。
15. API Key 泄露后怎么办？
立即在 Steam API Key 页面撤销或重新生成 Key；回到首页展开 Key 区域，点击“清除”；同时检查终端历史和其他曾粘贴 Key 的位置。不要将 Key 提交到仓库。
16. 为什么本地启动后无法打开页面？
先运行 bun run cf:d1:local 初始化本地 D1，再运行 bun run cf:dev；确认终端没有数据库、构建或端口错误，并访问 Wrangler 实际打印的地址。
17. Bun 版本还能继续使用吗？
可以。仓库保留 dev:bun、build:bun 和 start:bun 作为本地备用；Cloudflare Workers 开发使用 cf:dev。
找不到答案时，请按教程逐项排查。
