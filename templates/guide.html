详细使用教程

1. 这个工具是什么

Steam 游玩时光全景图读取 Steam Web API 返回的公开游戏列表、游戏名称、AppID 和累计游玩分钟数，再用游戏官方封面组成拼图。游玩时间越长，卡片面积通常越大；权重经过柔化，避免一款游戏占满画面。

工具不会读取 Steam 密码、令牌、私信、好友聊天、支付信息或库存私密内容。查询会经过本站 Cloudflare Worker，成功的数据进入 Cloudflare D1 的 24 小时缓存和站点排行榜；浏览器导出的 PNG 不会上传到图片服务器。

2. 使用前准备

  • 准备一个可正常访问的 Steam 账号。
  • “我的个人资料”和“游戏详情”必须允许公开读取。
  • 不能单独隐藏总游戏时间。
  • 浏览器需要启用 JavaScript，并允许下载文件。
  • 部分网络环境无法访问 Steam API 或 cdn.steamstatic.com 图片资源，此时需检查网络、代理或防火墙。

3. 如何公开 Steam 游戏资料

  1. 登录 Steam。
  2. 打开个人资料。
  3. 点击“编辑个人资料”。
  4. 进入“隐私设置”。
  5. 将“我的个人资料”设置为“公开”。
  6. 将“游戏详情”设置为“公开”。
  7. 取消勾选“即使用户可以查看我的游戏详情，也始终保持我的总游戏时间为私密”。
  8. 保存设置，再回到本工具重试。

Steam 客户端与网页端的入口文字可能略有不同，但都在个人资料编辑页的隐私设置中。设置变化也可能需要几分钟才生效。

4. 如何找到 SteamID64

方法一：完整个人资料网址

如果地址类似下面这样，可直接粘贴完整网址：

https://steamcommunity.com/profiles/7656119xxxxxxxxxx

方法二：自定义用户名网址

也可直接粘贴自定义地址，工具会让 Steam API 解析用户名：

https://steamcommunity.com/id/example

方法三：直接复制 SteamID64

SteamID64 通常是 17 位数字，例如 76561198000000001。它可以直接输入，不需要先转换。

5. 如何申请 Steam Web API Key

  1. 在浏览器登录 Steam。
  2. 打开 Steam Web API Key 申请页面。
  3. 填写页面要求的域名。正式站点可填写实际域名；仅用于本地测试时，可按 Steam 当前页面允许的格式填写 localhost。
  4. 阅读并接受相关条款。
  5. 复制生成的 Key，粘贴到首页的可选区域。

不要公开 Key、不要截图发布，也不要提交到 GitHub。Key 仅存入当前浏览器的 localStorage，查询时通过 X-Steam-API-Key 请求头发送给本站 Worker，再由 Worker 请求 Steam；不会写入 URL、响应正文、日志或 D1。留空时会使用站点 Secret，但该 Secret 不会发送到浏览器。

如果 Key 泄露，请立即返回申请页面撤销或重新生成，并在首页点击“清除”删除浏览器中的旧 Key。

6. 单账号生成教程

  1. 打开首页。
  2. 输入 Steam 用户名、SteamID64 或完整资料网址。
  3. 如果本地服务已经配置环境变量，通常无需填写 API Key。
  4. 点击“生成我的全景图”。
  5. 等待账号解析、游戏读取和封面加载。
  6. 查看游戏数量、总时长、平均时长与最常玩的游戏。
  7. 电脑端悬停封面，手机端点击封面，可查看名称和时长。
  8. 点击“下载高清图片”。
  9. 选择位置保存 PNG 文件。

7. 多账号合并教程

在同一个输入框里输入多个账号，可用逗号、中文逗号、空格、换行或分号分隔。重复账号会自动去重。

76561198000000001 76561198000000002 76561198000000003

也可以输入：

account1, account2, account3
  1. 点击生成后，本站 Worker 以最多 3 个任务的并发限制分别读取账号。
  2. 相同 AppID 的游玩分钟数自动相加，封面只显示一次。
  3. 结果按合并后的总时长排序。
  4. 结果页会分别列出成功和失败账号；至少一个成功时仍会生成。
  5. 点击下载，文件名会使用 merged-N-accounts 标识。

8. 如何下载图片

  1. 等待所有封面加载完成；加载失败的封面会使用替代色块。
  2. 点击“下载高清图片”。
  3. 浏览器 Canvas 只绘制拼图主体，不包含导航、按钮或错误信息。
  4. 游戏较多时需要更长时间；系统会自动限制最长边与总像素，必要时降低比例。
  5. 如果失败，请先等待图片完成、刷新页面并重试；也可更换 Chrome、Edge 或 Firefox 的新版本。

9. 常见错误处理

Steam 账号不存在 / 用户名无法解析

检查拼写，去掉多余符号；优先改用资料网址中的 17 位 SteamID64。

资料不公开 / 游戏详情未公开 / 总时间被隐藏

按本页第 3 章逐项设置，保存后等待几分钟再重试。

Steam API Key 无效

回到首页清除旧 Key，重新复制申请页面显示的 Key；确认没有多复制空格。

Steam API 请求频率过高

等待几分钟后重试，或在首页使用自己的 Key。不要连续快速刷新多个账号。

网络无法访问 Steam API

请求由本站 Worker 发往 Steam；若 Steam 上游暂时不可用，请稍后重试。

Steam 图片资源加载失败

确认浏览器能访问 cdn.steamstatic.com；单个封面失败不影响其他卡片，下载时会用替代卡片。

没有找到任何已游玩的游戏

确认账号确有记录时长的游戏，并检查三项隐私设置。游玩不超过 10 分钟的游戏按原项目规则不会纳入。

多个账号中部分读取失败

结果仍会生成。查看结果页红色状态行，单独复制失败账号回首页排查。

D1 数据库尚未初始化

站点管理员需先创建 D1 绑定并执行仓库中的 schema.sql；本地开发可运行 bun run cf:d1:local。

本地开发端口被占用

关闭占用端口的程序，或按 Wrangler 输出选择其他端口后重新运行 bun run cf:dev。
