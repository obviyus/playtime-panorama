你的游戏时间，另一种观看方式

Steam 游玩
时光全景图

根据一个或多个 Steam 账号的游戏时长，生成一张独一无二的游戏封面全景图。添加多个账号时，相同游戏的游玩时长会自动累计；玩得越久，封面越醒目。

示意效果：同一张图里，游戏封面面积会随累计游玩时间变化。

每个账号只需填写以下任意一种格式，无需同时填写多种：

  • SteamID64： 17 位数字，例如 76561198000000001
  • 自定义用户名： Steam 个人资料网址中 /id/ 后面的内容，例如 example_user
  • 完整个人资料网址： 例如 https://steamcommunity.com/id/example_user 或 https://steamcommunity.com/profiles/76561198000000001

可一次填写多个账号，账号之间可使用换行、英文逗号、中文逗号、 空格、英文分号或中文分号分隔，最多填写 10 个账号。

Steam Web API Key

API Key 仅保存在当前浏览器中，并随查询请求发送到本地服务，由本地服务请求 Steam Web API。程序不会将该 Key 持久保存到数据库。申请 API Key

只读取 Steam 公开的游戏名称与游玩时间，不需要也不会读取 Steam 密码。个人资料、游戏详情和总游戏时间必须公开。

完整工具，而不只是一个输入框

从账号读取到图片保存，一次完成

保留原项目轻量、快速的特点，同时把多账号、隐私说明、错误处理和下载流程做得更清楚。

时长决定面积

使用柔化权重，突出长期游玩的作品，也让中低时长游戏保持可辨认。

多账号自动合并

相同 AppID 只出现一次，不同账号的游玩分钟数会自动相加。

高清 PNG 下载

由浏览器 Canvas 在本地生成，只导出拼图主体，并自动限制安全尺寸。

只读公开资料

请求 Steam Web API 的公开游戏数据，不接触密码、好友私信或支付信息。

电脑与手机都可用

网格会随页面宽度重新排布，触屏点击封面也能查看游戏信息。

开始前只需确认三件事

资料允许公开读取

将“我的个人资料”和“游戏详情”设为公开，并取消隐藏总游戏时间。

输入一个或多个账号

直接粘贴用户名、17 位 SteamID64 或完整资料网址，工具会自动识别和去重。

生成并下载

等待封面加载完成，查看统计与账号状态，然后下载高清 PNG。
